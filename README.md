# Brain Tumor Classification Project

Ez a projekt agydaganatok MRI képeken történő osztályozásával foglalkozik hagyományos gépi tanulási (Machine Learning) algoritmusok és képfeldolgozási technikák (Feature Extraction) segítségével.

## Mappaszerkezet
- `data/`: Az MRI képek és maszkok helye (lokális, nincs verziókövetve).
- `notebooks/`: Kísérleti Jupyter notebookok.
- `src/`: A projekt Python forráskódja.
